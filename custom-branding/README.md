# Eigen GovChat-branding

Plaats hier de bestanden waarmee je de standaard GovChat-NL-branding wilt
overschrijven. De bestandsnamen zijn exact:

| Bestand | Formaat / afmetingen |
| --- | --- |
| `logo.svg` | SVG; schaalbaar vectorbestand. |
| `favicon-32x32.png` | PNG, exact 32 × 32 pixels. |
| `favicon-16x16.png` | PNG, exact 16 × 16 pixels. |
| `apple-touch-icon-180x180.png` | PNG, exact 180 × 180 pixels. |

Je hoeft niet alle vier bestanden aan te leveren. Elk geldig bestand dat je
hier plaatst, overschrijft alleen het bestand met dezelfde naam; voor
ontbrekende bestanden blijft de GovChat-NL-standaardbranding actief.

Bestanden in deze map zijn organisatie-eigen en worden niet naar Git gecommit.
